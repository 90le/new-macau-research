# 新澳门预测助手 · Windows 本地工具

当前稳定版：**1.18.0**。下载安装程序后即可运行，无需 Python、Node 或 Go。

[下载安装程序](https://github.com/90le/new-macau-research/releases/latest/download/NewMacauResearch-Setup.exe) · [版本说明与所有发行包](https://github.com/90le/new-macau-research/releases)

## 使用

1. 运行 `NewMacauResearch-Setup.exe`，按提示完成当前用户安装。
2. 打开程序查看本期已保存预测、号码属性、开奖对照及数据分析。
3. 程序后台运行且网络可用时，默认每60秒核验指定开奖源，先结算已有预测，再保存下一期。
4. 关闭网页不会关闭后台；托盘可打开页面、暂停同步或退出。开机启动按安装时及设置中的选择执行。

电脑关闭或程序退出期间无法生成本机开前预测；恢复后会追齐数据，缺发与失败保留，不补造过去的预测。

## 以后怎样升级

从1.18.0开始，正式安装版默认自动检查本仓库的稳定版本，下载并验证发布者签名、版本、平台、大小及SHA-256；下次正常启动自动安装。新版实际启动通过核验后完成交接，保留本机数据、安装身份和偏好。可在设置中关闭自动软件更新。

1.17.1及更早版本没有这套软件更新能力，需要先运行一次新版安装器。便携运行可查询版本，自动安装需要有效安装标记。

软件更新签名与Windows Authenticode代码签名不同。本版未附Windows发布者证书，首次安装可能出现系统发布者提示。请核对下载地址确为本仓库。

## 功能与成绩

- 本期预测、号码属性、近期表现和预测依据。
- 历史复盘、方法对比、共同误杀及独立研究任务。
- 号码走势、冷热遗漏、生肖、波色、大小与单双、头尾、分段、组合间隔。

本版沿用既有14核心方法。软件更新不等于预测成功率提升；历史回放与开前记录分别显示，不同数据目录的成绩不互相替代。研究目标尚未整体达到，历史表现不保证未来。

## 分发与数据

Release包含安装程序、`update-manifest.json`和`SHA256SUMS.txt`。用户运行数据保存在本机，与程序目录分开；本仓库不存放用户运行目录、账号凭据或发布私钥。

这是本地预测与分析参考工具。后续模型和页面改进将通过明确版本发布，客户端不执行下载的任意脚本。
