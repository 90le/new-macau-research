# 新澳门预测助手 · Windows 发布渠道

本仓库用于分发本地 Windows 预测与分析工具 **NewMacauResearch** 的正式安装包、版本说明和软件更新清单。

## 当前状态

发布渠道正在建设。目前本仓库尚未提供经过本渠道签名与完整安装验证的稳定版本。正式可用时，请从本仓库的 **Releases** 下载对应的 Windows 安装包；开发中的功能不代表已经交付。

## 产品用途

- 本机获取和核对公开开奖数据，保存每期预测与开奖后的比较结果。
- 展示号码、属性、走势、遗漏和方法比较，作为研究与使用参考。
- 在后台运行时按规则更新，升级保留本机历史数据与设置。

预测结果不代表未来保证；历史回放与开前留档成绩分别显示。

## 软件更新

正式更新将使用本仓库的 GitHub Releases，并由客户端验证发布者签名、版本、平台、文件大小和 SHA-256。软件更新、开奖数据更新及研究方法的采用是不同流程。

未来发布资产约定：

- `NewMacauResearch-Setup.exe`：当前用户 Windows 安装程序。
- `update-manifest.json`：签名更新清单。
- 对应版本说明与校验信息。

本仓库不存放用户本机数据、研究工作目录、账号凭据或发布私钥。
